## Peças × pergunta

| Peça | Audiência | Pergunta |
|------|-----------|----------|
| Catálogo | CS, produto, comercial técnico | O sistema faz X? |
| Manuais | Quem opera | Como eu faço X no meu papel? |
| Comercial cliente | Decisor da empresa | Por que contratar o Taktchat? |
| Comercial parceiro | Revenda | Por que revender / por que ser whitelabel? |
| Técnica | Dev, infra, integrador | Como se encaixa na stack? |

## Linguagem

- PT-BR.
- Manuais: “você” e receitas numeradas.
- Comercial: problema → capacidade → resultado. Sem adjetivo vazio.
- Técnico: Node, React, PostgreSQL, Redis, Bull, Socket.IO, Baileys, Meta Cloud API. Sem secrets.
- Não inventar `profile` que o código não tem.
- Não vender roadmap como entregue.
- Não afirmar “sem risco de banimento”. API Oficial reduz risco de conta pessoal; política da Meta e cadência de campanha continuam valendo.

## Posicionamento

- **Nome:** Taktchat
- **Uma frase:** plataforma de atendimento e campanhas no WhatsApp, multi-empresa, com opção de revenda.
- **Dois canais:** Baileys (QR) e API Oficial (Meta).
- **Dois mercados:** empresa cliente e parceiro whitelabel.
- **Núcleo operacional:** o ticket — conversa trabalhada em fila, com responsável, tags e histórico.
