# Roteiro de demo (10–15 min)

Ambiente: local, logins em `../../09-logins-locais.md`.

1. **Landing** (`/landing`) — dor, planos, revenda (1 min). Overlay de API só aparece se o health falhar de verdade.
2. **Login** — `atendente@taktchat.local` (1 min).
3. **403 na home** — “atendente não usa dashboard” (20 s). Ir para Atendimento.
4. **Ticket Maria** — aberto, histórico, tag Urgente (3 min). *Se a lista não carregar, mostrar no banco/admin.*
5. **Ticket João** — pendente: aceite (2 min).
6. **Admin** — logout, `admin.cliente@taktchat.local`: filas, usuários, conexão CONNECTED, Tags Kanban (lanes automáticas) (3 min).
7. **Dono ou parceiro** — hierarquia empresas (2 min) *melhor na rodada parceiro*.
8. **Fecho** — próximo passo é WhatsApp real (QR).

Não prometer pipeline de oportunidade. Encerrar aplica a lane; o quadro ainda lista sobretudo tickets abertos/pendentes.
