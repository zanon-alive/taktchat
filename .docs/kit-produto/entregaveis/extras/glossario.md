# Glossário

Cópia de trabalho do kit (2026-08-22). Origem: `../../12-glossario.md`.

| Termo | Significado |
|-------|-------------|
| Ticket | Conversa em atendimento para a equipe |
| Fila | Time/assunto (Suporte, Vendas…) |
| Conexão | Número Baileys ou WABA Oficial |
| Pendente / Aberto / Encerrado | Sem atendente / com atendente / fechado |
| Dual channel | Baileys + API Oficial no mesmo produto |
| Whitelabel | Empresa `type=whitelabel` que revende |
| Dono / super | `user.super` na empresa `platform` |
| Supervisor | User com flags extras, não é profile |
| Licença | Sem ela ativa, login de cliente/parceiro bloqueia |
| Lane | Coluna do quadro de conversas (`kanban=1`) |
| CRM de conversa | Contato + ticket no WhatsApp — não é pipeline de oportunidade |
| Tag operacional | Urgente, VIP (`kanban=0`); não é coluna do quadro |
| Landing | Página pública `/landing` |
