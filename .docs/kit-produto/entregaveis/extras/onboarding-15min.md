# Onboarding em 15 minutos

## Trilha atendente

Login → `/tickets` (não ficar no 403) → abrir Maria → entender pendente do João → resposta rápida.

## Trilha admin da empresa

Login → conexões (precisa conectar de verdade depois) → filas → usuários nas filas → settings básicas.

## Trilha parceiro

Login → conferir licença → empresas filhas → enviar acesso ao admin da filha.

Senhas e e-mails: `../../09-logins-locais.md`.
