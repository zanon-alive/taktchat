# Manual — Dono da plataforma

## Este manual é para você se…

`super = true` na empresa plataforma. Logins: `dono@taktchat.local` (kit) ou `admin@admin.com`.

## O que você não precisa fazer

Atender o chat do cliente final.

## Tarefas

1. Empresas: plataforma, whitelabels, clientes diretos.
2. Planos (direct vs whitelabel).
3. Licenças e vencimento.
4. Relatório de cobrança por parceiro.
5. Todas as conexões (`/allConnections`) e anúncios.
6. Saúde do sistema (filas Redis, sessões WhatsApp).

## Login de teste

API 200 nesta versão. Home do dono não foi fotografada (sessão de UI focou na atendente).

## Quando der erro

Empresa 1 deve permanecer `type = platform`. Usuário `super` só nessa empresa.
