# Campanhas

## Para que serve

Disparo em massa para listas, com cadência e relatório.

## Onde fica

`/campaigns`, `/contact-lists`, `/campaigns-config` — se o plano tiver campanhas (`useCampaigns` / `cshow`).

## Quem usa

Admin / marketing. Atendente em geral não dispara.
